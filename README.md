# Premier League Analytics Dashboard

## Overview

This project analyzes data from the 2022/23 Premier League season using SQL, PostgreSQL, and Tableau. The goal was to create an interactive dashboard that provides insights into team performance, goals scored, league standings, and stadium attendance.

## Tools Used

* PostgreSQL
* SQL
* Tableau Public
* GitHub
* CSV Data Sources

## Dashboard Features

### Key Performance Indicators (KPIs)

* Total Goals Scored
* Total Matches Played
* Average Stadium Attendance
* Average Goals Per Match

### Visualisations

* Premier League Final Table
* Goals Scored by Home Team
* Average Attendance by Stadium

## Key Insights

* Manchester City finished the season as league champions with 89 points.
* Arsenal finished second with 84 points.
* The league recorded 1,084 goals across 380 matches.
* The average goals per match was 2.85.
* Old Trafford recorded the highest average attendance.
* Manchester City scored the most goals at home.
